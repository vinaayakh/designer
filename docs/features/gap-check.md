# Gap Check

A Gap Check reviews one Production version against the compliance regimes in the Brief (SOC 2, HIPAA) and against security practices.

- It runs automatically after Conversion. Run it again on any version with **Check again**.
- The runtime works out which Knowledge Base Records apply to which components and files the controls that are about process rather than design. The Assistant judges the rest.
- Each finding is **met**, **unmet** or **outside the diagram** (needs evidence from configuration or policy), tied to the elements involved, with suggested fixes.

**Fix** on unmet findings drafts a Proposal that addresses them; review it like any other. Gap Reports are never edited after they're written, so older reports stay as they were.

A Gap Check reports and suggests; it is not an audit. Controls that live in configuration, policy and procedure still need their own evidence.
